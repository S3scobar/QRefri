# QRefri

Una solución web colaborativa orientada a optimizar la gestión de suministros del hogar y centralizar las compras en tiempo real mediante acceso directo por código QR.

---

## Planteamiento del Problema

En entornos compartidos o familiares, la reposición de insumos suele presentar fallas de comunicación: compras duplicadas, olvido de artículos agotados y falta de claridad al momento de adquirir productos en el supermercado.

Este proyecto resuelve dicha fricción mediante una interfaz ligera accesible desde un código QR físico en la cocina, permitiendo que cualquier integrante registre faltantes al instante sin intermediarios ni descargas de aplicaciones adicionales.

---

## Funcionalidades Principales

* **Acceso Inmediato sin Autenticación Compleja:** Enfoque mobile-first optimizado para escaneo y registro rápido de insumos.
* **Persistencia y Sincronización en la Nube:** Integración directa con base de datos relacional para reflejar adiciones y actualizaciones al instante entre múltiples dispositivos.
* **Categorización Estructurada:** Segmentación de productos por áreas del hogar (Nevera, Despensa, Aseo, Otros) para facilitar el recorrido en el punto de compra.
* **Registro de Cantidades y Unidades:** Soporte para métricas personalizadas por insumo.
* **Modo Supermercado:** Sistema de verificación interactiva de artículos adquiridos y depuración de registros completados.
* **Exportación de Datos:** Conversión de la lista a texto plano para su distribución mediante whatsapp.

---

## Arquitectura Técnica

* **Frontend:** HTML5 semántico, CSS3 estructurado mediante variables personalizadas, JavaScript (ES6+ Vanilla).
* **Backend y Base de Datos:** Supabase (PostgreSQL con Row Level Security y API REST).
* **Despliegue y Hosting:** Vercel.

## Configuración del Entorno

### 1. Clonar el repositorio

```bash
git clone https://github.com/S3scobar/lista-nevera.git
cd lista-nevera

```

### 2. Estructura de la Base de Datos

Ejecutar la siguiente sentencia SQL en el panel de Supabase:

```sql
create table if not exists compras (
  id bigint generated by default as identity primary key,
  nombre text not null,
  cantidad text default '',
  categoria text default 'General',
  comprado boolean default false,
  creado_en timestamp with time zone default timezone('utc'::text, now()) not null
);

alter table compras enable row level security;

create policy "Acceso total a la lista" 
on compras 
for all 
using (true) 
with check (true);

```

### 3. Variables de Conexión

Configurar las constantes de entorno en `app.js`:

* `SUPABASE_URL`
* `SUPABASE_ANON_KEY`
